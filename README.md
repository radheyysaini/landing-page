# Landing Page

A simple landing page built with HTML, CSS, and Flexbox.

## About

This project is a recreation of a landing page built as part of
The Odin Project's Foundations curriculum.

Live site: https://radheyysaini.github.io/landing-page/ 

## Built With

- HTML
- CSS
- Flexbox

## What I Learned

- Structuring a webpage with HTML
- Using Flexbox for layout
- Working with parent and child elements
- Aligning elements along the main and cross axes
- Controlling spacing, sizing, and text wrapping
- Creating reusable CSS classes
